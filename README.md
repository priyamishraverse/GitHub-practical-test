## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Add your profile photo to the `images` folder as `profile.jpg`.
4. Add your certificate images to the `certificates` folder using the filenames listed above.
5. Open `index.html` in a browser. You can also use the **Live Server** extension in VS Code.

No additional packages or installations are required.

## Customize Before Publishing

1. Replace `YOUR_USERNAME` in `index.html` with your actual GitHub, LinkedIn, and Instagram usernames.
2. Check that the email address and all profile details are correct.
3. Add your actual profile photo and certificate images.
4. Test the navigation, certificate previews, and social links on desktop and mobile.
